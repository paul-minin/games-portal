# Arcade (4 Spiele)

Kleine Game-Website (nur HTML/CSS/JS) mit 4 Spielen. Läuft offline, ohne Build.

## Starten

- Öffne `index.html` im Browser.

## Spiele

- Runner
- Snake
- Flappy
- Breakout

## Steuerung (kurz)

- **Menü**: Spiele auswählen, dann Start
- **Space / Klick / Touch**: Start bzw. Aktion (je nach Spiel)
- **R**: Neustart
- **Esc**: zurück ins Menü

Highscore (**Best**) wird pro Spiel im Browser gespeichert.

- **Space** oder **Klick/Tippen**: springen / starten
- **R**: Neustart

## Dateien

- `index.html` – Seite + UI
- `style.css` – Layout/Styles
- `game.js` – Arcade + Spiele-Logik (Canvas)
